{% call ui.section("Threshold pace") %}

About the fastest pace you could hold for half an hour. Dieter takes it from your best race or hard 10–40 minute effort in the last 6 months. If you also have a short all-out effort, like a mile, it uses that to sharpen the number.

{% if e.cs_pace %}

Yours is {{ e.cs_pace }}/mi, {{ e.cs_how }}.

{% else %}

You don't have one yet: it needs a race or a hard 10–40 minute run in the last 6 months. You can also enter race times on the Usual week page.

{% endif %}

Sports scientists call this "critical speed".

{% endcall %} {% call ui.section("Speed points") %}

Picture a pacer running beside you at threshold pace for the whole run. Every metre you get ahead of them is one point. Running slower than the pacer doesn't cost points; it just scores nothing.

{% if e.examples %}{% set a = e.examples.steady %}{% set b = e.examples.fast %}
  • One 400 in {{ a.seconds }} s: the pacer covers {{ a.pacer }} m, so you're {{ a.points }} m ahead = {{ a.points }} points.
  • One 400 in {{ b.seconds }} s: the pacer covers only {{ b.pacer }} m, so that's {{ b.points }} points.{% if e.examples.fast_reps %} {{ e.examples.fast_reps }} of those score about the same as 18 of the {{ a.seconds }}-second ones.{% endif %}
{% endif %}

That's why faster running counts for more per second.

{% endcall %} {% call ui.section("Safe limit") %}

Your weekly speed points averaged over the {{ e.chronic_weeks }} weeks before, × {{ e.ratio }}. Injury research finds that jumping more than about half again over what you've been doing is when injuries pile up. Building gradually raises the limit with you.

Up to {{ e.well_over }}× the limit is "a little over"; past that is "well over".

{% endcall %} {% call ui.section("Near-sprint running") %}

Metres run at 90% of your top speed or faster. That's the hardest running on your hamstrings, so it gets its own safe limit, worked out the same way.

{% endcall %} {% call ui.section("Fast stretches") %}

Anything at least about a third faster than your easy pace for 6 seconds or more. Short bursts count as strides only if they get close to threshold pace.

{% endcall %}

These are estimates from Strava's second-by-second data, not lab tests.
